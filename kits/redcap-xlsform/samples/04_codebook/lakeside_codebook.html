How to read this codebook
  • Variable is the column name in a REDCap export. Codes are what is stored; labels are what people see.
  • Checkbox questions export one column per option, named variable___code (three underscores): 1 = ticked, 0 = not ticked.
  • Shown when: the question only appears when this is true. A blank value can mean 'not shown' as well as 'not answered'.
  • Dates are stored as YYYY-MM-DD whatever the display format.
  • Each instrument has a status column (instrument_complete): 0 = Incomplete, 1 = Unverified, 2 = Complete.
  • Identifiers are flagged so they can be removed from de-identified exports.
  • Longitudinal project: each row of an export is one record at one event (column redcap_event_name).
  • Repeating instruments get extra rows with redcap_repeat_instrument and redcap_repeat_instance filled in.
Identifiers (remove or protect before sharing data)
  • dob: What is your date of birth?
  • contact_phone: Phone number for follow-up reminders
