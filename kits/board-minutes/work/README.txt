Client jobs go here, one folder per client and meeting, for example:

  work/acme-hoa/2026-10-14/input/    transcript, agenda, board list, client template
  work/acme-hoa/2026-10-14/output/   minutes.json, clean transcript, .docx, .xlsx, .pdf, questions

This folder is ignored by git (see ../.gitignore), so client files are never committed.
The cloud container is temporary: download what you deliver before the session ends.
